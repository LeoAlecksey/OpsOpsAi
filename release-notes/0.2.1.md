## OpsOpsAi 0.2.1 — модели скачиваются быстрее

- **Параллельная загрузка.** Движок, модель и модуль зрения скачиваются одновременно, а каждый
  файл — в 8 соединений (раньше в 4). На быстром интернете установка модели заметно короче.
- Докачка после обрыва по-прежнему работает: нажмите «Установить» ещё раз, и загрузка продолжится
  с того места, где остановилась. Каждый файл проверяется по контрольной сумме.
- Общая полоса прогресса для всей установки.
- На Linux ARM64 приложение понятно объясняет, если системе не хватает glibc 2.38 для запуска моделей.

Приложение предложит обновление само.
