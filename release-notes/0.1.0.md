## OpsOpsAi 0.1.0 — ранний доступ

Первая сборка OpsOpsAi — бесплатного приложения для локального ИИ.

**Что есть в этой версии**

- Приложение для macOS (Apple Silicon), Windows (x64) и Linux (x64 и ARM64).
- Интерфейс чата в тёмной теме: история, контекст, скиллы — пока как каркас.
- Автообновление: следующие версии установятся из приложения сами, с проверкой подписи.
- Журнал диагностики (Настройки → Открыть папку журналов).

**Чего пока нет**

Локального чата с моделью: установка движка, выбор и загрузка модели под ваш компьютер
появятся в следующих версиях. 0.1.0 нужна, чтобы проверить установку и автообновление
на ваших системах.

**Установка**

- macOS: `.dmg`. Сборка пока не подписана Apple: при первом запуске закройте предупреждение,
  откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть»
  (на macOS до 15 — правый клик по приложению → «Открыть»).
- Windows: `-setup.exe`. Сборка не подписана сертификатом: SmartScreen может предупредить —
  «Подробнее» → «Выполнить в любом случае».
- Linux: `.AppImage` (любой дистрибутив) или `.deb` / `.rpm`.
